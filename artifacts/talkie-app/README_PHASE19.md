# Talkie Chat — état final Phase 19

La version livrée après les phases 13–19 est une messagerie complète :

- messages texte en temps réel ;
- messages vocaux ;
- photos ;
- vidéos avec durée maximale de 5 minutes ;
- accusés envoyé/délivré/lu ;
- indicateur de saisie ;
- aperçu du dernier message et non-lus ;
- modification et suppression des messages ;
- stockage persistant des médias ;
- PWA et notifications push.

Le PTT et WebRTC ont été retirés pendant la Phase 13. Les anciennes références historiques présentes dans le README principal documentent les anciennes phases et ne représentent plus l'architecture finale.

Pour la recette finale, consulter `../PHASE19.md` et `MANUAL_TESTING.md`.
